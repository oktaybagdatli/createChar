# CreateChar

A practical step-by-step D&D character creator built with Next.js and TypeScript.

## Current milestone

- Nine-step character creation flow
- Live character summary
- Ability modifiers and proficiency bonus
- Local draft saving
- Responsive dark tactical interface
- Review and browser print/PDF foundation

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
